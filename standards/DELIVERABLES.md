## 1. Assemble the evidence packet

| Component | What it must contain | Failure to catch |
| :--- | :--- | :--- |
| Brief and scope | Prompt version, audience, length, authorized task | Solving a different assignment |
| Question and answer | Bounded question and the answer the evidence currently permits | A topic label standing in for an argument |
| Evidence map | Used claim IDs, source locators, and destination paragraphs or slides | Citations that do not support the sentence |
| Reasoning | Relevant concepts, inference, strongest rival, counterevidence | A sequence of summaries without an explanation |
| Decision reconstruction | Actors, authority, timeline, alternatives, and known outcomes where relevant | Treating approval as implementation or benefit |
| Limits | Missing evidence, edition differences, uncertainty, and exclusions | Completeness implied by polished presentation |
| Personal contribution | User-owned reflection and evaluative choices | Invented experience or AI-authored autobiography |

A narrow assignment can disclose the limits of a reviewed subset. It need not resolve every semester uncertainty. A class master brief requires review across its declared scope. Both require human verification of the claims actually used.

## 2. Build the argument

For each section, record its purpose, supporting evidence, inference, and transition. The order should follow the reader's needs.

| Move | What the reader needs |
| :--- | :--- |
| Establish the inquiry | A specific urban issue and an authentic reason to investigate it |
| Explain current understanding | Relevant evidence and the concept that changes its interpretation |
| Test the explanation | A credible alternative, conflicting observation, or missing record |
| State the implication | A warranted conclusion, practical possibility, or consequential learning question |

This is an editorial scaffold, not a mandatory essay formula. The assignment governs. Check that the analysis names the place, infrastructure or ecological relationship, decision authority, affected populations, and relevant action. Retain only what advances the inquiry.

## 3. Choose the form

| Memo or blog | Presentation |
| :--- | :--- |
| One central argument, developed through connected paragraphs | One central argument, developed through a timed storyboard |
| Evidence adjacent to the claim; locators in the companion evidence map | One assessable claim per slide; source and limitation visible where needed |
| Tables or diagrams only when they reduce explanatory burden | Visuals carry evidence or explain a relationship; notes carry spoken detail |
| Edit for purpose, reasoning, voice, citations, and required word count | Rehearse aloud; revise to measured delivery time |

### Presentation planning

Each slide record contains a title, purpose, evidence IDs, visual source, spoken explanation, limitation, and allotted time. A conceptual diagram must be labeled as such. A data graphic needs units, dates, system boundary, source, and uncertainty.

| Provisional five-minute sequence | Time |
| :--- | ---: |
| Question and place | 40 seconds |
| Urban stakes | 60 seconds |
| Theory and evidence | 90 seconds |
| Interpretation and limitation | 70 seconds |
| Implication or next question | 40 seconds |

These timings are planning suggestions, not course requirements. For eight minutes, use the additional time for comparison, alternatives, and how the understanding changed. Rehearsal determines the final allocation.

## 4. Review the artifact

| Review | Acceptance evidence |
| :--- | :--- |
| Source fidelity | Human review covers the claims used, with locators and unresolved limits recorded |
| Reasoning | The stated conclusion follows from the evidence; alternatives receive a fair account |
| Student authorship | Mark understands the argument and confirms personal reflections and evaluative judgments |
| AI disclosure | The acknowledgment accurately describes assistance and student verification |
| Presentation | Markdown or exported pages are inspected; labels, tables, sources, and contrast remain readable |
| Delivery | The final file matches the reviewed version and the authorized sharing scope |

For slides, render every slide at presentation size, inspect for clipping and legibility, and reopen the exported deck or PDF. Record a missing visual inspection as an open check. Structural validation alone cannot certify layout or scholarship.

## 5. Record the release

Keep the artifact version, prompt version, evidence map, word count or rehearsal duration, limitations, Mark's review, AI acknowledgment, and submission status together. An existing file or repository release does not establish that an assignment was submitted.

The course allows AI assistance with acknowledgment and student responsibility (`SYL`, PDF p. 7; `TA-03`). The [governance policy](../governance/AI-GOVERNANCE.md) implements that responsibility; no automated check can certify the student's understanding or endorsement.
