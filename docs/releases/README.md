## What a release establishes

A regular release identifies a repository edition ready for public distribution with its stated scope and limitations. Research can remain in progress within that edition. Source verification, human review, assignment submission and measured outcomes retain their own records; release publication does not advance those states.

Prereleases identify previews of a repository edition. The earlier `review` tags remain published as history, with their original descriptions. Pending scholarly review alone does not require every future research checkpoint to be a prerelease. The GitHub publication record, tag and successful post-merge checks establish delivery.
