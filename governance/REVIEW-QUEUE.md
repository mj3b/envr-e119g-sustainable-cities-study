## Record each adjudication

| Field | Required content |
| :--- | :--- |
| Target and version | Claim/gate ID and digest of inspected content |
| Reviewer and date | Actual human identity and UTC review date |
| Material inspected | Edition, page/timestamp, surrounding context and any independent record |
| Judgment | Accept, narrow, hold, reject or abstain; scope and reason |
| Correction | Changed interpretation and dependent artifacts, if any |
| Update condition | Evidence or change requiring renewed review |

Only an actual acceptance represented by a valid approval receipt can count toward promotion. Other dispositions belong in review notes and correction history; they must not be encoded as approval. [Review receipts](../cross-course/review-receipts.json) are currently empty.
