**Purpose:** record actual attempts, corrections, and changes in understanding.

| Student entries | Why this is intentionally unfilled |
| :--- | :--- |
| None recorded in this file | The repository cannot supply Mark's recollection, understanding, performance, or personal change of mind |

## Entry form

Copy this form after a real study attempt. Keep the initial answer so the correction remains inspectable.

| Field | Record |
| :--- | :--- |
| Date and task | Actual date; retrieval question or exercise ID |
| Initial answer | What you wrote or said before checking |
| Evidence checked | Claim ID, source, exact locator, and relevant qualification |
| Correction or confirmation | What changed, or why the original answer survived scrutiny |
| Reason | The distinction, calculation, or observation responsible |
| Remaining uncertainty | What the check did not resolve |
| Next review | A date or an event, such as the arrival of a missing record |

## What counts as learning evidence?

| Record | What it can establish |
| :--- | :--- |
| A preserved answer and corrected calculation | A specific reasoning error was identified |
| A revised question tied to new evidence | The inquiry changed in an identifiable way |
| A belief retained after a fair test | Scrutiny occurred even without a change of mind |
| A polished AI answer | An artifact exists; student understanding still needs demonstration |

Try the [evidence laboratory](EVIDENCE-LAB.md) or [discussion rehearsal](discussion-prep.md). Source errors belong in the canonical claim and omission records as well; this learning log does not silently correct them.
