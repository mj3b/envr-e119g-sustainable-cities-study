# How the research is done

[Home](../README.md) / Methods · [Case guide](../research/cerrillos/README.md)

The substantive method is documentary case analysis: connect a bounded claim to the instrument, authority and action that the record establishes. AI-assisted production and software checks support that work; they answer different questions from scholarly review.

| Method or record | Purpose |
| :--- | :--- |
| [Research-integrity protocol](RESEARCH-INTEGRITY.md) | Source identity, rival evidence, interpretation, correction and human approval |
| [Measurement protocol](MEASUREMENT.md) | Define units, comparators and denominators; separate observed values from prospective calculations |
| [Research design](../METHODOLOGY.md) | Explain which methods can answer which questions |
| [AI disclosure](AI-DISCLOSURE.md) and [system register](AI-SYSTEMS.md) | Identify actual assistance, supplied outputs, deterministic checks and unused tools |
| [Translator adaptation](TRANSLATOR-BRIDGE.md) | Specify a bounded task and its allowed evidence |
| [Optional Jev protocol](../experiments/jev/README.md) | Prepare a separately gated claim-support diagnostic; no live study evaluation recorded |
| [Assurance checks](../governance/README.md) | Reproduce structural and repository checks without certifying source truth |

The [activity record](ai-activity.json) documents performed work. A proposed method has no measured result until the necessary observations and review exist.
