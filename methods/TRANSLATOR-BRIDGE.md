# Research-to-Decision Translator: bounded adaptation

The owner's phrase “Apply Translator” is interpreted here as the **Applied AI Research Translator**, now presented as **Research-to-Decision Translator** under Node & Norm. The repository identity was resolved through GitHub; this is not a natural-language translation service. [Inspected upstream README](https://github.com/node-and-norm/applied-ai-research-translator/blob/main/README.md).

The upstream README describes source intake, falsifiable claims, bounded tasks, evaluation plans, abstention, human-gated decisions, and deterministic decision summaries. This study adapts that artifact pattern. Upstream runtime code has not been installed or executed here, and no claim of upstream compatibility, certification, or external validation is made. The owner is associated with both projects; this is self-developed infrastructure, not independent confirmation of the Cerrillos analysis.

| Translator element | Urban-research use |
| :--- | :--- |
| Source intake | Identify the actual instrument/version and access limitation |
| Claim | Separate what a source says from what the researcher infers |
| Bounded task | Compare a specified legal effect across named passages |
| Evaluation | Check attribution, qualifications, contrary evidence, and missing dependencies |
| Abstention | Stop a technical or outcome inference that exceeds the inspected evidence |
| Human gate | Record acceptance, revision/override, rejection, or deferral by a human |
| Decision summary | Assemble the recorded decision without inventing approval |

The [example card](translator-card.json) applies the pattern to the narrowed inquiry. It is an AI-authored candidate record with human review pending. “Accept for review” is not “the claim is true,” and neither is permission to implement a development project. No source-closure status is modified by this bridge.
